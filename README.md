# Reno's Finest Details | Smart Detailing Website Demo

A mobile-friendly, single-file website prototype. Includes animated hero effects, service cards, an interactive rule-based quote estimator, a stylized before/after comparison, and a prefilled SMS inquiry.

## Preview
Open `index.html` in any modern browser.

## Deploy with GitHub + Vercel
1. Create a new GitHub repository.
2. Upload `index.html`, `README.md`, and `vercel.json` at the repository root.
3. In Vercel, select **Add New > Project**, import the GitHub repository, and deploy.
4. Framework preset: **Other**. No build command is required.

## Important before launch
- Quote prices are invented demo values and are **not** approved business prices.
- Hero and comparison visuals are third-party stock images. Replace with authorized photos of the actual detailer and real work. The comparison is an illustrative visual effect, not an actual before/after.
- This is **not connected to an AI API**. It is a working rule-based interactive prototype.
- SMS links may behave differently by browser/device. Test on mobile.
- Confirm business contact details and get owner approval before going live.

## Customize
Edit colors in CSS `:root`, image URLs in `.hero` and `.comparison`, and estimator demo values in `calculate()` in `index.html`.
